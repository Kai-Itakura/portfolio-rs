読み取り側：案件と技術

このサイトは別アプリのデータを読むだけ。v1 はコードに書いたデータを「一覧を返す関数」の裏に隠し、API ができたら関数の中身だけを差し替える。

  • id: ProjectId提案別アプリの ID は ULID。API との照合に使う。
  • title: String決定
  • description: String決定
  • kind: ProjectKind決定

表示のときに計算する値

件数もゲージも、案件と技術からいつでも導ける。保存すると元のデータと食い違う余地が生まれ、ゲージは最大値が変わるたびに全行が変わるので、DB には置かない。
